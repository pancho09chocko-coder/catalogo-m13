# Soporte Digital M13

Proyecto desarrollado completamente desde Termux en Android.

## Tecnologías

- HTML5
- CSS3
- JavaScript
- Git
- GitHub
- Termux

## Funciones

- Catálogo de servicios
- Cuestionario para Páginas Web
- Cuestionario para Diseño Digital
- Cuestionario para Soporte Técnico
- Resumen automático
- Envío de información por WhatsApp
